# K-NPU News Monitor

국산 AI 반도체 3사(퓨리오사AI·리벨리온·딥엑스)의 국내 보도를 매일 수집해, 커뮤니케이션 책임자가 아침에 읽을 1페이지 브리프를 만드는 에이전트입니다.

만든 이유: 보도 모니터링 서비스는 "몇 건 나왔다"를 알려줍니다. 커뮤니케이션 책임자에게 필요한 것은 다른 질문입니다. 기사의 주어가 우리 회사인가 파트너인가, 부정 프레임이 반복되고 있는가, 경쟁사가 어떤 주제로 점유율을 가져가고 있는가. 이 도구는 그 세 가지를 자동으로 분류합니다.

## 무엇을 하나

1. 구글뉴스 RSS에서 회사별 최근 N일 보도를 수집 (중복 제거)
2. 헤드라인을 세 축으로 분류
   - 주제: 이슈·부정 / 투자·IPO·정책자금 / M&A·빅테크 / 해외 / 고객 상용화 / 파트너십·MOU / 제품·기술 / CEO·인물 / 정부·공공
   - 주어: 자사 주어 / 파트너 주어 (회사명이 헤드라인 앞쪽에 오는지로 판정)
   - 논조: 긍정 / 중립 / 부정 (키워드 규칙)
3. 회사별 비교표 + 부정 기사 우선 목록 + 주제별 기사 목록을 Markdown으로 출력
4. 선택: `--llm` 옵션으로 Claude가 "오늘 대응 필요 / 프레임 변화 / 다음 주 발표 기회" 5줄 요약을 덧붙임

## 실행

```bash
python npu_news_monitor.py --days 1              # 어제 하루
python npu_news_monitor.py --days 180 --json     # 6개월, JSON 원자료 포함
python npu_news_monitor.py --from-file sample_output/raw_headlines_2026-10-27.md   # 네트워크 없이 샘플 재현
ANTHROPIC_API_KEY=... python npu_news_monitor.py --days 7 --llm
```

의존성: Python 3.9+ 표준 라이브러리만 사용. `--llm`은 `pip install anthropic`.

매일 07:30 자동 실행은 cron 한 줄이면 됩니다.

```
30 7 * * 1-6 cd /path/to/repo && python npu_news_monitor.py --days 1 --llm --out daily/$(date +\%F).md
```

## 샘플 결과 (2026-10-27, 최근 180일)

`sample_output/brief_2026-10-27.md` 참고 (원자료 `sample_output/raw_headlines_2026-10-27.md`를 `--from-file`로 돌린 결과). 요약:

| 회사 | 건수 | 자사 주어 비율 | 부정 | 상위 주제 |
|---|---|---|---|---|
| FuriosaAI | 100 | 39% | 5 | 파트너십·MOU·실증(24), 해외 사업(21) |
| Rebellions | 99 | 47% | 4 | M&A·빅테크(18), 투자·IPO·정책자금(18) |

이 표 한 줄이 이 도구를 만든 이유입니다. 두 회사의 보도량은 같지만 자사가 주어인 기사 비율이 다르고, 퓨리오사는 파트너십·해외, 리벨리온은 M&A·IPO가 보도를 끌고 갑니다. 규칙 기반 분류라 수작업 분류(별도 메모)와 수치가 조금 다릅니다. 경향은 같습니다.

## 한계와 다음 단계

- 키워드 규칙 분류는 정확도 80% 수준. 운영 시에는 Claude 분류로 전환 (프롬프트는 `llm_summary` 함수 참고)
- 구글뉴스 RSS는 검색어당 100건 상한. 전수 집계는 네이버 뉴스 API로 교체
- 다음 단계: 기자별 보도 이력 테이블, 주간 프레임 점유율 차트, 슬랙 자동 발송
